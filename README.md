# 👨🏻‍💻 Customer Behavior Analysis | Data Analytics Portfolio Project

An end-to-end data analytics project exploring customer purchasing behavior using **Python, PostgreSQL, SQL, and Power BI**.

## 📌 Project Overview

The objective of this project is to simulate a real-world business analytics workflow, transforming raw customer data into meaningful insights that support data-driven decision-making.

The project follows an end-to-end analytics process:

### 🐍 1. Data Preparation & Exploratory Data Analysis (Python)
- Import and explore the raw dataset using Pandas.
- Identify and handle missing values and duplicate records.
- Clean, transform, and prepare the data for analysis.
- Perform Exploratory Data Analysis (EDA) to identify patterns and trends.
- Prepare the dataset for database integration.

### 🗄️ 2. Data Analysis (PostgreSQL & SQL)
- Design and create the database structure.
- Load the cleaned dataset into PostgreSQL.
- Write SQL queries to answer business questions.
- Analyze customer segments, purchasing patterns, product preferences, and customer loyalty.
- Extract actionable insights to support business decisions.

### 📊 3. Data Visualization & Business Intelligence (Power BI)
- Connect PostgreSQL to Power BI.
- Develop an interactive dashboard.
- Create KPIs and visualizations to monitor customer behavior.
- Identify key trends, patterns, and business opportunities.

### 📑 4. Reporting & Business Recommendations
- Summarize the main analytical findings.
- Translate data insights into actionable business recommendations.
- Prepare a professional project report.
- Create a presentation to communicate results and recommendations to stakeholders.

## 🚀 How to Run This Project

### 1. Clone the repository

```bash
git clone https://github.com/DavidCabezas115/customer_behavior_analysis.git

cd customer_behavior_analysis
```

### 2. Explore the Jupyter Notebook

Open `customer_behavior_cleaning.ipynb`.

This notebook covers:
- Data import and exploration.
- Data quality assessment.
- Data cleaning and transformation.
- Exploratory Data Analysis (EDA).
- Database connection and data loading.

### 3. Set Up the PostgreSQL Database

- Create a PostgreSQL database.
- Configure the database connection in the Python notebook.
- Execute the notebook to load the cleaned dataset.
- Open `sql_customer_analysis.sql`.
- Run the queries to answer the business questions.

### 4. Build the Power BI Dashboard

- Open `customer_behavior_dashboard.pbix`.
- Connect Power BI to your PostgreSQL database.
- Refresh the dataset.
- Explore the interactive dashboard and its visualizations.

### 5. Review the Final Deliverables

Explore the project report and presentation to understand the key findings, business insights, and recommendations derived from the analysis.
